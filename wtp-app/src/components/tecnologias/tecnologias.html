Tecnologías utilizadas

Frontend
  • Angular
  • HTML5
  • CSS3
  • Bootstrap
Backend

Base de datos
  • MongoDB
Deploy
  • Vercel (frontend)
  • Render (backend)
Autenticación
  • JWT simulado

¿Por qué lo hicimos así?

Elegimos Angular por su estructura modular y escalabilidad.

Node + Express por su rapidez para construir APIs REST.

MongoDB por su flexibilidad con datos de productos que varían por tienda.
