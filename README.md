# What_The_Price_2026
WTP (What The Price) es una plataforma web enfocada en la comparación de precios de productos en múltiples categorías, con especial énfasis en tecnología. 

 # Documentación de Rutas y Navegación - Frontend
Este documento detalla el flujo de navegación y las funcionalidades disponibles en la interfaz de usuario de What The Price (WTP).

# Página Principal (Landing Page)
Punto de entrada principal del proyecto que ofrece una visión general de la plataforma.

Navbar: Acceso global a la navegación y autenticación.

Sección de Filtros: Herramientas de segmentación por precio, tienda y categoría.

Sección de Ofertas: Acceso directo a promociones destacadas en diversas tiendas asociadas.

Footer: Información corporativa y enlaces de contacto profesional vía LinkedIn.

# Sistema de Navegación (Navbar)
El Navbar centraliza el control de la experiencia del usuario mediante dos áreas principales:

Menú Lateral (Ajustes)
Accesible mediante el icono de tres líneas (hamburguesa):

Favoritos: Redirige a la página de productos guardados por el usuario.

Perfil: Acceso a la gestión de cuenta y datos personales.

Sobre Nosotros: Despliega un modal/texto emergente con la misión de la empresa.

Contacto: Enlace directo para soporte técnico vía WhatsApp.

Autenticación (Lado Derecho)
Registro / Login: Flujo de acceso que permite al usuario crear una cuenta nueva o iniciar sesión en una cuenta existente.

# Búsqueda y Resultados
Search Page: Ruta activada al interactuar con la barra de búsqueda. Permite visualizar y comparar los productos encontrados.

Filtros Avanzados: Ubicados en la página de resultados para refinar la búsqueda por criterios específicos (tiendas, rangos de precio, etc.).

# Detalle de Producto
Al seleccionar un producto desde la búsqueda o las ofertas, se accede a la vista detallada que incluye:

Información General
Lista Comparativa: Visualización de precios en diferentes establecimientos para encontrar la mejor oferta.

Valoraciones: Resumen de las mejores reseñas de otros usuarios.

Productos Relacionados: Sugerencias basadas en la categoría del producto actual.

Funciones Premium (Usuario Plus)
Los usuarios con suscripción Plus tienen acceso a rutas y datos exclusivos:

Logística: Detalles sobre costos de envío y tiempos de entrega estimados.

Asistente IA: Integración de Inteligencia Artificial que analiza y explica cuál es la mejor opción de compra basándose en todas las características y variables disponibles.

# Acciones de Usuario
Compra: Enlace directo para proceder a la adquisición del producto.

Favoritos: Opción para marcar productos y verlos posteriormente en la ruta correspondiente.
